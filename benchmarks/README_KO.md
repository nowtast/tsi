# Benchmark

이 directory는 frozen TSI evidence에서 파생한 versioned research benchmark를
보관한다. 각 release는 answer 공개 여부, 독립 단위와 정보 정책을 명시하고, 모든
reference value를 hash가 고정된 source artifact에 연결하며, machine-checkable report
형식을 제공해야 한다.

- `structural_attribution_v0_1/`: graph/head recovery와 held-out composition
  prediction을 위한 공개 audit/development benchmark. Blind leaderboard가 아니다.
