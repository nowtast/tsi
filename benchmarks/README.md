# Benchmarks

This directory contains versioned research benchmarks derived from frozen TSI
evidence. A benchmark release must state whether its answers are public, identify
its independent unit and information policy, link every reference value to a
hashed source artifact, and provide a machine-checkable report format.

- `structural_attribution_v0_1/`: public audit/development benchmark for graph
  and head recovery plus held-out composition prediction. It is not a blind
  leaderboard.
