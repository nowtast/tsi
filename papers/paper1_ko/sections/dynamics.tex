\section{Dynamics와 rollout stability}

Static structure만으로 transition model이 well-defined해지지는 않는다. Error를
측정하기 전에 update가 structural equivalence를 존중해야 한다.

Bisimulation metric은 reward와 transition information에서 Markov decision
process의 task-dependent behavioral distance를 구성한다
\cite{ferns2004metrics}. Lipschitz model 분석은 Wasserstein geometry에서
one-step error를 여러 단계로 전파한다 \cite{asadi2018lipschitz}. 아래
discrepancy는 bisimulation fixed point라고 주장하지 않으며 reward에서 유도되지도
않는다. Rollout theorem은 별도로 주어진 structural pseudometric과 Lipschitz
constant를 전제로 하는 조건부 결과이다.

\begin{definition}[Extended structural pseudometric]
$\mathcal X=\StrState(Q,\mathcal E)/\cong_{\mathrm{str}}$라 하자. Extended
structural pseudometric은 $\mathcal X_0\subseteq\mathcal X$ 위의
\[
\Dstr:\mathcal X_0\times\mathcal X_0\to[0,\infty]
\]
함수로서 symmetry, diagonal vanishing, triangle inequality를 만족하고
$+\infty$를 허용한다. Finite-distance component는 모든 pairwise value가
유한한 부분집합이다. Rollout theorem은 이 조건에 대한 조건부 결과이며,
특정 layer discrepancy가 자동으로 이 조건을 만족한다고 주장하지 않는다.
\end{definition}

\begin{proposition}[비공허한 discrepancy의 예]
임의의 $\mathcal X_0$에 대해
\[
\Dstr^{\mathrm{disc}}(x,y)=
\begin{cases}0,&x=y,\\1,&x\ne y,\end{cases}
\]
는 $\mathcal X_0$ 위의 structural metric이다. 모든
$T:\mathcal X_0\to\mathcal X_0$는 이 metric에 대해 $1$-Lipschitz이다.
\end{proposition}

\begin{proof}
Symmetry와 diagonal vanishing은 자명하다. $x\ne z$이면 $x\ne y$ 또는
$y\ne z$ 중 하나가 성립하므로 triangle inequality가 성립한다. Map은
zero distance를 늘릴 수 없고 양의 입력 거리는 1뿐이므로 Lipschitz 주장도
따른다.
\end{proof}

이 discrete 예제는 rollout에 대해 의도적으로 퇴화되어 있다. One-step tolerance가
$1$보다 작으면 predicted class와 true class가 같아야 하고, $1$ 이상이면 diameter가
$1$이므로 bound가 vacuous할 수 있다.

Metric--measure 결과는 non-discrete admissible instance를 준다. State $\Sigma$의
tagged label을 포함한 induced full-support metric--measure state를 $M(\Sigma)$라
하고
\[
\Dstr^{\mathrm{mm}}([\Sigma],[\Sigma'])
=\Delta_{\mathrm{mm},1}(M(\Sigma),M(\Sigma'))
\]
로 정의하자. Structural isomorphism은 label- 및 measure-preserving isometry를
유도하므로 이 값은 representative 선택과 무관하다. Symmetry, diagonal vanishing,
triangle inequality에 의해 이는 $\mathcal X$ 위의 extended structural
pseudometric이다. 그러나 metric은 아니다. 값이 0이어도 metric--measure layer만
식별할 뿐 simplicial complex나 generator relation의 일치를 강제하지 않기 때문이다.

\begin{assumption}[Quotient-defined Lipschitz action model]
$\mathcal X_0$를 true update와 predicted update에 대해 invariant한
finite-distance component라 하자. 각 action $a$에 대해
$T_a,\widehat T_a:\mathcal X_0\to\mathcal X_0$가 well-defined이고,
$T_a$가 extended structural pseudometric $\Dstr$에 대해 $L_a$-Lipschitz이며,
predicted-rollout에서 estimate가 사용되는 모든 $z$에 대해
$\Dstr(\widehat T_a z,T_a z)\leq\varepsilon_a$라고 가정한다.
\end{assumption}

Well-definedness는 equivariance assumption이다. 즉 isomorphic input
representative는 isomorphic output을 내야 한다. 이는 state definition에서
따라오지 않는다. Recurrence에는 pseudometric이면 충분하고, 서로 다른
quotient class를 분리하려면 genuine metric이 필요하다.

\begin{theorem}[Action-conditioned rollout bound]
Action $a_1,\ldots,a_n$와 같은 initial class $x_0$에 대해
$x_i=T_{a_i}x_{i-1}$, $\widehat x_i=\widehat T_{a_i}\widehat x_{i-1}$로
두면
\[
\Dstr(\widehat x_n,x_n)\leq
\sum_{i=1}^n\varepsilon_{a_i}\prod_{j=i+1}^nL_{a_j}
\]
이다. Empty product는 $1$이다.
\end{theorem}

\begin{proof}
$e_i=\Dstr(\widehat x_i,x_i)$라 두면 triangle inequality와 가정으로
\[
e_i\leq\Dstr(\widehat T_{a_i}\widehat x_{i-1},T_{a_i}\widehat x_{i-1})+
\Dstr(T_{a_i}\widehat x_{i-1},T_{a_i}x_{i-1})\leq\varepsilon_{a_i}+L_{a_i}e_{i-1}.
\]
$e_0=0$에서 시작하는
induction으로 표시된 합을 얻는다.
\end{proof}

\begin{proposition}[Uniform Lipschitz control 없는 uniform rollout bound의 실패]
공통 one-step error bound만으로는 Lipschitz constant가 무한히 커질 수
있는 model family에 대해 nontrivial multi-step bound를 얻을 수 없다.
\end{proposition}

\begin{proof}
$[0,1]$에 $\Dstr(u,v)=c|u-v|$를 두고
$T_M(u)=\min\{1,Mu\}$, $\widehat T_M(u)=\min\{1,Mu+\eta\}$로 둔다.
$T_M$은 $M$-Lipschitz이고 one-step discrepancy는 $M$과 무관하게
$c\eta$ 이하이다. 0에서 시작해 $M\eta+\eta\geq1$이 되도록 $M$을
선택하면 두 번째 단계에서 predicted state는 1에 도달하지만 true state는
0이다. 따라서 공통 Lipschitz bound가 없으면 $\eta\to0$에서도 fixed
two-step error가 남는다.
\end{proof}

\begin{proposition}[Quotient equivariance의 독립적 필요성]
Isomorphic input state를 non-isomorphic output state로 보내는
representative-level update는
$\mathcal X=\StrState(Q,\mathcal E)/\cong_{\mathrm{str}}$ 위에
well-defined update를 유도하지 못한다.
\end{proposition}

\begin{proof}
$\Sigma\cong_{\mathrm{str}}\Sigma'$이고 representative-level rule이 이를
$\Theta$, $\Theta'$로 보내며 $\Theta\not\cong_{\mathrm{str}}\Theta'$라 하자.
Input의 quotient class는 같지만 두 representative가 서로 다른 output class를
만들므로 quotient class 위의 함수가 될 수 없다.
\end{proof}
