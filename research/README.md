# Prospective Research

This directory contains designs for studies that are separate from the frozen
Paper 01/03/04 cohort. A directory here is not confirmatory evidence unless its
own contract is frozen before seed generation and its sealed execution is
recorded.

- `research_a/`: finite-sample support-recovery efficiency under a common
  supplied graph.

The current release-candidate manuscripts are not revised to include results
from this directory before their first public versions.
